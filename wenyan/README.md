# 文言拾句（七年级起步，跨年级积累）

入口：`/wenyan/`。原来的《伤寒论》网站不受此模块影响。

## 两套相互隔离的数据

- **正式背诵/关联学习**：26篇示范背诵文与经整理的字词、句式。每条正式“关联学习”至少包含真实古文、句意译文、当前字的具体义项/句式说明，并与原句比较；不能直接把命中字形视为同义或同句式。
- **后台候选语料**：完整《世说新语》36门1130则、常见小学初高中古文候选源、9部诗文蒙学资料（唐诗三百首、古文观止、千家诗、增广贤文、三字经、千字文、朱子家训、声律启蒙、幼学琼林），以及古籍开放数据集中的十三经、史记、汉书、历代史书、资治通鉴等。老师可检索并选用，但必须补齐准确译文、义项、词性/语法功能，才会进入学生阅读界面。

小学/初中/高中分类用作候选检索优先级，**并不表示已经核对全国历年各版本教材的全部选文**。语料量、失败源与版本来源，以 `/wenyan/evidence/expanded-manifest.json` 为准。后台检索有限流与缓存；源站限制抓取时可能只有部分候选。

## 自建内容

**我的 → ＋实词／虚词／句式** 或 **积累 → 录入**：输入字词/句式、原文、篇名出处、准确翻译、义项代码、用法区别。也可以“从后台原典找更多例句”：搜索字词或典型句子，按小学、初中、高中、名言、史记、资治通鉴、世说新语等筛选，选中原文后填写译注。

自建内容保存在**当前浏览器** `localStorage`（`wenyan-recall-study-v1`），支持 JSON 导出/导入，也纳入“我的→导出全部数据”。清理浏览器缓存或换设备前请先导出；目前没有云端账号同步，更不应宣称修改直接写回 GitHub。

## 拼音

只对生僻字与有把握的古文特殊读音显示行内 ruby 拼音，不全字注音。多音字需按上下文判断，例如《陈太丘》“尊君在不”`fǒu`、《邹忌》“期年”`jī`、《杞人忧天》“舍然”`shì`。未经校核的多音字不自动猜。

## 来源/许可

- 世说新语及选篇原典：中文维基文库，校录文本遵守原页面署名及 CC BY-SA 4.0 条款。
- 古文诗歌及蒙学参考：`chinese-poetry/chinese-poetry`，MIT 授权。
- 大规模经史候选：`gujilab/chinese-classical-corpus`，该数据集标示 CC0 1.0；涉及底本时请查源出处。
- 所有现代汉语译文都需要校核，不能把未完成的网络抓取视为正式教学译注。请遵守具体版本现代译文的版权。
- 在线版由 GitHub Pages 静态构建，原始语料规模和更新结果受网络、源站限流与 Github Actions 部署情况影响。

## 质量门禁

`node wenyan/scripts/test-study.mjs` 与 `node wenyan/scripts/test-enhancements.mjs` 检查数据基本格式、敏感多音字、字义/句式链接和手动录入入口。每次自动部署先通过这些检查。浏览器端还应检测无初始内容、滑动、词义链式跳转及自建例句即时出现。
