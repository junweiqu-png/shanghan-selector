# 文言拾句（七年级起步，跨年级积累）

入口：`/wenyan/`。原来的《伤寒论》网站不受此模块影响。

## 两套相互隔离的数据

- **正式背诵/关联学习**：26篇原有示范文 + 10篇分级兴趣/初中常见选文，配原创逐句译文、正文单字释义、句式发现提示和每篇两道不计时小游戏。每条正式“关联学习”至少包含真实古文、句意译文、当前字的具体义项/句式说明，并与原句比较；不能直接把命中字形视为同义或同句式。
- **后台候选语料**：完整《世说新语》36门1130则、常见小学初高中古文候选源、9部诗文蒙学资料（唐诗三百首、古文观止、千家诗、增广贤文、三字经、千字文、朱子家训、声律启蒙、幼学琼林），以及古籍开放数据集中的十三经、史记、汉书、历代史书、资治通鉴等。老师可检索并选用，但必须补齐准确译文、义项、词性/语法功能，才会进入学生阅读界面。

小学/初中/高中分类用作候选检索优先级，**并不表示已经核对全国历年各版本教材的全部选文**。语料量、失败源与版本来源，以 `/wenyan/evidence/expanded-manifest.json` 为准。后台检索有限流与缓存；源站限制抓取时可能只有部分候选。

## 自建内容

**我的 → ＋实词／虚词／句式** 或 **积累 → 录入**：输入字词/句式、原文、篇名出处、准确翻译、义项代码、用法区别。也可以“从后台原典找更多例句”：搜索字词或典型句子，按小学、初中、高中、名言、史记、资治通鉴、世说新语等筛选，选中原文后填写译注。

自建内容保存在**当前浏览器** `localStorage`（`wenyan-recall-study-v1`），支持 JSON 导出/导入，也纳入“我的→导出全部数据”。清理浏览器缓存或换设备前请先导出；目前没有云端账号同步，更不应宣称修改直接写回 GitHub。

## 拼音

只对生僻字与有把握的古文特殊读音显示行内 ruby 拼音，不全字注音。多音字需按上下文判断，例如《陈太丘》“尊君在不”`fǒu`、《邹忌》“期年”`jī`、《杞人忧天》“舍然”`shì`。未经校核的多音字不自动猜。

## 来源/许可

- 世说新语及选篇原典：中文维基文库，校录文本遵守原页面署名及 CC BY-SA 4.0 条款。
- 古文诗歌及蒙学参考：`chinese-poetry/chinese-poetry`，MIT 授权。
- 大规模经史候选：`gujilab/chinese-classical-corpus`，该数据集标示 CC0 1.0；涉及底本时请查源出处。
- 所有现代汉语译文都需要校核，不能把未完成的网络抓取视为正式教学译注。请遵守具体版本现代译文的版权。
- 在线版由 GitHub Pages 静态构建，原始语料规模和更新结果受网络、源站限流与 Github Actions 部署情况影响。

## 质量门禁

`node wenyan/scripts/test-study.mjs` 与 `node wenyan/scripts/test-enhancements.mjs` 检查数据基本格式、敏感多音字、字义/句式链接和手动录入入口。每次自动部署先通过这些检查。浏览器端还应检测无初始内容、滑动、词义链式跳转及自建例句即时出现。

## 2022义务教育课程标准第四学段：本轮扩容（2026-11-11）
- 依据教育部2022版语文课程标准的**随文学习字词语法、阅读浅易文言文、在语境中理解和思辨**原则，而非假设存在全国统一“中考必考字表”。初中教学用书/中考选文因学年和地区不同，不能直接标记为“100%覆盖考纲”。
- 正文现在是唯一核心分母：所有正式篇目 `lines[][0]` 中的汉字均计入独立字数/篇目字数，既有重点注释单字为优先子集；辅助例句与后台古籍候选绝不扩大分母，也不会自动让主文某字算“掌握”。
- 原有26篇保持原顺序与学习进度；新10篇以趣味探案→山水→情境推理分级递进（正文约43—331汉字，注意“汉字数”不等于标点后总长度）；每篇2道基于原句的轻量挑战，答错可重试，无倒计时，不强迫做题。
- 句式专设“找线索→尝试还原→理解效果”的渐进提示，优先覆盖判断、省略、反问、宾语前置、状语后置、被动、词类活用、使动、意动等；“同一字有不同语境义”仍由逐句审校决定。
- 逐句翻译、兴趣题与注释是本站原创教学释读。课文底本可能有异文，实际教材版本应以学生所在学校为准。
- 核验报告 `/wenyan/evidence/character-coverage-report.json` 除已校核比率外，还明确给出正文独立汉字、正文全部汉字位置、重点字/本字义项核验情况。该报表仅对**本站正文**负责，不能替代地方中考内容标准/真实题测。
- 参照：教育部《义务教育语文课程标准（2022年版）》 https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582344386456.pdf
- 2025年长春市中考曾使用《邹忌讽齐王纳谏》与课外《读书强记法》对照阅读，提示需要课内理解 + 课外迁移，不可只做背诵卡（中国吉林网 2025-06-27）。
- 本阶段未覆盖全部初中教材诗文/义项和全部中考题型。可读性、逐句审校和学习兴趣优先于虚假的100%完成率。

### 质量门禁
`node wenyan/scripts/test-junior.mjs` 对课内外标注边界、逐字注释、篇幅梯度、出处链接、句式提示出处和趣味题答案做持续回归。
`node wenyan/scripts/audit-character-coverage.mjs` 按正文动态统计，不再把整词/关联候选作为主分母。
