# 易错字颜色与全文虚线字选择

易错色针对中学文言阅读中常见的误译类型，不是全国考试失分率排名，也不把所有生僻字都当作易错字。

| 颜色 | 提醒 | 例子 |
| --- | --- | --- |
| 红 | 古今易混 | “走”表示跑，“狱”表示诉讼案件，“存亡之秋”的“秋”表示紧要时刻 |
| 紫 | 通假借字 | “尊君在不”的“不”同“否”；普通否定用法不套用此色 |
| 橙 | 词类活用 | “不蔓不枝”的“蔓、枝”，“犬坐”的“犬”，“洞其中”的“洞” |
| 蓝 | 多义字、虚词的具体用法 | “之”作代词、动词；“以”表凭借、因为等；“善”表示擅长 |

依据正文“篇名＋原句＋字位”的既有释义判断。通假、活用必须有明确的释义或语法线索；不同字位不能互借解释。姓名、地名不因字形相同而染色。“以为”表示认为，不自动当作意动用法。关联句只有其已注释的目标字或可精确定位的课文字位参与判定，未明确的字不猜测。颜色和悬停文字只提示类别，不提前展示隐藏的答案。

分类参考：

- 香港教育局[《中学中国语文建议学习重点》（2021 年修订）](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/SEC_LO_2021.pdf)，语文学习基础知识列有多义字、通假、词类活用及文言句式。
- 香港教育局[《中国语文课程和评估指引（中四至中六）》补充说明](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/Supp%20notes_CHI%20LANG_CLE.pdf)，含《桃花源记》古今词义、词类活用教学示例。
- 本项目已整理的课文逐字释义及课堂例句。按教材语境选定用法，不宣称覆盖所有地区的全部考试。

虚线字选择按照正文逐句显示完整原文，保留标点及每个重复字。每个汉字位置都是独立复选框，分母为实际出现次数：《狼》202 个字位，而非 123 个不同字。51 篇共 6446 个正文汉字位置全部参与选择。

保存仍使用 `wenyan-highlight-v1`，单篇条目升级为 `{version:2,lines,positions}`。旧版字数组按原有语义迁移为该字全部出现的位置；新选择可对同字不同位置独立设置。导出、导入携带此数据。正文改动后，仅保留仍能按原句准确对应的位置，不把标记移到另一个字上。易错颜色与用户选择的虚线互不影响。
