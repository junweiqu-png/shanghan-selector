# 中医经典学习与方证辨识系统

项目目标已经从“经方推荐器”收敛为一个共享知识底座上的三个入口：**古籍 / 搜索 / 辨证**。

## V0.7 核心架构
- `古籍`：本地 TXT 阅读器。仓库内 `books/*.txt` 与浏览器导入的 TXT 使用同一个阅读器。
- `搜索`：横向全文搜索所有已装入古籍，支持多关键词共现，例如 `口渴 + 小便不利`。
- `辨证`：保留症状 + 脉象合参，但重点转向相近方鉴别、反证和经典证据链。
- 关键词互链：阅读和经典证据中的重要术语可继续跳词条；词条底部可转入本地古籍全文搜索。
- 经方差分：从候选方直接比较相近方的共同骨架、加药、去药、剂量/写法变化和对应条文变化。

## 本地古籍规则
古籍原文以 UTF-8 TXT 保存，原文只读。章节索引、关键词、方剂、药物、医家观点、用户经验和 AI 结果全部作为旁路数据保存，不污染原文。

`books/manifest.js` 记录书名、作者、版本、路径和别名。把对应 TXT 放进 `books/` 后网页会自动加载；也可以在“古籍”页直接导入多个 TXT，浏览器会保存到本机 IndexedDB。

同一部书的不同版本应并存，而不是互相覆盖，例如：
- `伤寒论-宋本.txt`
- `伤寒论-成本.txt`

这样版本差异本身也能成为研究对象。

## 经方差分模型
经方不再只作为孤立的药物清单。每个方剂记录：
- 方族
- 原始药味与原始剂量写法
- 关键条文
- 最值得比较的相近方
- 版本差异提醒

比较时优先显示：
1. 哪些药不变（共同骨架）
2. 哪些药加入/去掉
3. 同一味药的剂量或写法如何变化
4. 条文中的证候如何同步变化
5. 版本是否存在异文

首批差分覆盖桂枝汤类、四逆汤/通脉四逆汤、小柴胡汤/大柴胡汤、桂枝汤/麻黄汤等代表性组合。

## 设计原则
系统始终围绕三个问题：
- **它是什么？**
- **它和最像的那个有什么不同？**
- **凭什么？原文在哪里？**

不同医家的理论不强行统一。仲景原文、后世注解、现代资料和个人经验分层显示。

## 医疗边界
本项目用于经典学习、资料检索和辨证思维训练，不是自动诊断器或处方器。经典方剂的药味和古代剂量仅用于历史文本比较，不代表现代剂量换算或个人用药建议。含附子、麻黄及攻下类方剂尤其不能根据网页自行试用。

## 运行
直接打开 `index.html`，或用任意静态 Web Server 托管。GitHub Pages 已配置自动发布。
