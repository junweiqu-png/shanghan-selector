# 伤寒论方证辨识器

一个纯静态、可离线使用的《伤寒论》方证学习与症状整理网页。

## V0.3
- 在症状选择之外，新增脉象选择与“脉证合参”排序
- 脉象支持组合选择，如浮+紧、浮+缓、弦+细、沉+微
- 核心脉象作为高权重证据，辅助脉象作为加分证据
- 已选择脉象但未命中某方关键脉象时，会对该方扣分
- 结果展示症状支持、关键脉象、脉象支持、缺失核心线索和反证
- 继续保留麻黄、附子、承气汤类等安全警示

## V0.2 基础能力
- 症状按寒热汗出、头项全身、胸胁呼吸、胃肠、口渴二便等分组
- 采用“核心证 + 兼证 − 反证”的透明匹配逻辑
- 收录六经方向的代表性经方
- 红旗症状优先提示就医
- 纯前端，无账号、无数据库，不上传健康信息

## 重要说明
本项目不是自动诊断器或处方器。网页排名只表示当前所选症状与脉象和内置方证特征的相对匹配，用于经典学习、症状整理和就医沟通。

脉象本身需要规范诊脉才能可靠判断；网页不会根据单一脉名直接给出处方。真实临床仍需结合病程、年龄、基础病、舌象、既往用药、体格检查及必要的现代医学检查。

任何经典方剂都不应仅凭网页结果自行服用，含附子、麻黄及攻下类方剂尤其如此。

## 运行
直接打开 `index.html` 即可；也可用任意静态 Web Server 托管。

## GitHub Pages
仓库已配置 GitHub Actions 自动发布。`main` 分支更新后会重新部署。

## 经典来源
方证结构依据《伤寒论》通行本核心条文整理。不同版本在字词、标点、条文序号上可能有差异。V0.3 对“脉浮紧”“脉沉”“脉洪大”“脉结代”等直接脉证关系优先采用原文或通行注本可明确对应的内容；其余标注为辅助脉象，不作为硬性定方条件。
