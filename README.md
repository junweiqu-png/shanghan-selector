# 伤寒论方证辨识器

一个以《伤寒论》方证为入口、逐步扩展为古籍学习与辨证训练系统的纯静态网页。

## V0.6 主动学习闭环
- 新增“治学训练台”：经典熟读、读记并行、先辨后看、临证返经典、阶段复盘、博采而有定见
- 新增随机经典回忆：先回忆主证、脉象、鉴别点，再揭示原文
- 候选方下增加“三问训练”：为什么是它、为什么不是相近方、什么反证会推翻它
- 可一键遮住经典原文，强迫先回忆再核对
- 可把条文或方证标记为“待复盘”
- 每个方证可写“我的按语”，仅保存在当前浏览器 localStorage
- 学习设计参考《名老中医之路》中反复出现的经典熟读、勤记、临证思考和阶段总结等治学路径；页面为功能化归纳，不摘抄整段现代书籍内容

## V0.5 古籍关键词互链
- 经典原文中的重要医学词可点击跳转
- 词条展示同一概念在不同经典医籍中的代表性原文
- 词条内部可继续点击其他关键词，形成递归知识网络
- 首批接入《黄帝内经》《难经》《脉经》《伤寒论》《金匮要略》《诸病源候论》《千金要方》《伤寒明理论》《医宗金鉴》等医籍入口

## V0.4 经典证据链
- 每个候选方增加“经典证据链”
- 优先列《伤寒论》直接条文，再列同书旁条、禁忌条文或古代医家解释
- 增加“脉法总则 · 古籍原文”区域
- 原文、后世注解和现代解释尽量分层展示

## V0.3 脉证合参
- 在症状之外加入脉象选择与排序
- 支持浮+紧、浮+缓、弦+细、沉+微等组合
- 关键脉象作为高权重证据，辅助脉象作为加分证据
- 显示脉象支持、缺失关键脉象和症状反证

## 基础能力
- 症状按寒热汗出、头项全身、胸胁呼吸、胃肠、口渴二便等分组
- 采用“核心证 + 兼证 + 关键脉象 − 反证”的透明匹配逻辑
- 收录六经方向代表性经方并保留安全警示
- 红旗症状优先提示就医
- 纯前端，无账号、无数据库，不上传健康信息

## 重要说明
本项目不是自动诊断器或处方器。网页排名只表示当前所选症状、脉象与内置方证特征的相对匹配，用于经典学习、症状整理和就医沟通。

古籍原文用于说明“为什么会想到这个方”，不等于现代临床已经排除了感染、心脑血管急症、急腹症、药物不良反应等其他疾病。脉象也需要规范诊脉才能可靠判断。

任何经典方剂都不应仅凭网页结果自行服用，含附子、麻黄及攻下类方剂尤其如此。

## 未来底座
计划把古籍逐步改为本地 TXT 原文库，原文只读；章节、关键词、方剂、药物、医家体系、用户经验和 AI 索引均作为旁路数据保存。阅读、全文检索、辨证、方剂差分和个人经验最终共享同一古籍知识底座。

## 经典来源
方证结构以《伤寒论》通行本条文为第一层依据；后世医家原文仅作为解释、互证和鉴别材料，不覆盖仲景原条。不同版本在字词、标点、条文序号和个别方名上可能有差异。
