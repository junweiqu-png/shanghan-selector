# 伤寒论方证辨识器

一个纯静态、可离线使用的《伤寒论》方证学习与症状整理网页。

## V0.2
- 症状按寒热汗出、头项全身、胸胁呼吸、胃肠、口渴二便等分组
- 采用“核心证 + 兼证 − 反证”的透明匹配逻辑
- 展示支持线索、缺失核心线索、反证、经典方证概括与鉴别点
- 收录六经方向的代表性经方，并对麻黄、附子、承气汤类等增加安全警示
- 红旗症状优先提示就医
- 纯前端，无账号、无数据库，不上传健康信息

## 重要说明
本项目不是自动诊断器或处方器。网页排名只表示当前所选症状与内置方证特征的相对匹配，用于经典学习、症状整理和就医沟通。

真实临床必须结合病程、年龄、基础病、舌脉、既往用药、体格检查及必要的现代医学检查。任何经典方剂都不应仅凭网页结果自行服用，含附子、麻黄及攻下类方剂尤其如此。

## 运行
直接打开 `index.html` 即可；也可用任意静态 Web Server 托管。

## GitHub Pages
仓库发布后，可在 GitHub 仓库 Settings → Pages 中选择默认分支根目录发布。

## 经典来源
方证结构依据《伤寒论》通行本核心条文整理。不同版本在字词、标点、条文序号上可能有差异，因此网页采用“方证线索概括”而非把条文编号作为诊断依据。
