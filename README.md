# 伤寒论方证辨识器

一个纯静态、可离线使用的《伤寒论》方证学习与症状整理网页。

## V0.4
- 每个候选方增加“经典证据链”
- 优先列《伤寒论》直接条文，再列同书旁条、禁忌条文或古代医家解释
- 已纳入《黄帝内经·素问·脉要精微论》《脉经》《伤寒明理论》《医宗金鉴》《伤寒论类方》《药征》《本经疏证》等原文/注解
- 每条古籍证据附书名、原文摘录、解释和可点击来源链接
- 增加“脉法总则 · 古籍原文”区域，帮助理解浮沉、数迟、代、细、涩等脉象的古典语境
- 条文编号在不同版本中可能不同，因此页面以书名和原文为主要定位依据

## V0.3
- 在症状选择之外，新增脉象选择与“脉证合参”排序
- 脉象支持组合选择，如浮+紧、浮+缓、弦+细、沉+微
- 核心脉象作为高权重证据，辅助脉象作为加分证据
- 已选择脉象但未命中某方关键脉象时，会对该方扣分
- 结果展示症状支持、关键脉象、脉象支持、缺失核心线索和反证

## V0.2 基础能力
- 症状按寒热汗出、头项全身、胸胁呼吸、胃肠、口渴二便等分组
- 采用“核心证 + 兼证 − 反证”的透明匹配逻辑
- 收录六经方向的代表性经方
- 红旗症状优先提示就医
- 纯前端，无账号、无数据库，不上传健康信息

## 重要说明
本项目不是自动诊断器或处方器。网页排名只表示当前所选症状、脉象与内置方证特征的相对匹配，用于经典学习、症状整理和就医沟通。

古籍原文用于说明“为什么会想到这个方”，不等于现代临床已经排除了感染、心脑血管急症、急腹症、药物不良反应等其他疾病。脉象也需要规范诊脉才能可靠判断。

任何经典方剂都不应仅凭网页结果自行服用，含附子、麻黄及攻下类方剂尤其如此。

## 运行
直接打开 `index.html` 即可；也可用任意静态 Web Server 托管。

## GitHub Pages
仓库已配置 GitHub Actions 自动发布。`main` 分支更新后会重新部署。

## 经典来源
方证结构以《伤寒论》通行本条文为第一层依据；后世医家原文仅作为解释、互证和鉴别材料，不覆盖仲景原条。不同版本在字词、标点、条文序号和个别方名上可能有差异。
